# Ofer-knowledge-rag Frontend

## :rocket: Overview

This folder is the client part of the Full Stack application.

## :computer: Technologies Used

Open WebUI is a scalable, feature-rich, and user-friendly artificial intelligence platform.

## :gear: Installation

Please run this command in the project root to install and configure:

1. ```powershell
   docker-compose up --build
   ```
2. Your app will be accessible at [http://localhost:3000](http://localhost:3000/)
